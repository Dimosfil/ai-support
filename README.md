# ai-support

[Общая основа системы поддержки](SUPPORT_SYSTEM_PLAN.md): сначала сайт, затем
Telegram с общей историей обращений. На 25.10.2026 реализована локальная основа:
встраиваемое ядро, SQLite, HTTP API и интерфейсы пользователя/оператора.

Работают создание и список обращений, переписка, внутренние заметки, назначение,
статусы и повторное открытие. Ядро проверяет tenant/владельца/роль, версии записей,
повторы запросов и лимиты. Сообщения, аудит и намерения уведомлений сохраняются
атомарно. Сохраняются черновики текущей вкладки.

Добавлен механизм G2.2: устойчивая доставка уведомлений с повторами, проверкой
получателей и отдельными результатами каналов. Есть входные адаптеры сервиса
и Telegram, транспорты Telegram/product. По умолчанию доставка выключена;
живое подключение сайта и бота ai-media-client — следующий согласованный шаг.
Контракты, настройка и миграция: [NOTIFICATIONS.md](docs/NOTIFICATIONS.md).

Стек: Node.js 24.14.1+ (ветка 24.x), ESM, встроенный SQLite, без внешних npm-пакетов.

```powershell
npm.cmd run dev:setup
npm.cmd start
```

Адрес и локальные ключи: [инструкция запуска](docs/LOCAL_RUN.md).
Проверка: `npm.cmd test`.

- [Контракт ядра и границы адаптеров](docs/CORE_CONTRACT.md)
- [HTTP API v1](docs/API.md)
- [Стек и ограничения](tools/project-memory/specs/technology-stack.md)

Гостевой доступ, вложения, диагностика и инциденты пока не реализованы.
Telegram-бот и внешние отправки требуют явного подключения адаптеров/получателей.
Локальный вход заменяется серверной identity
продукта при интеграции. Полный G1 и production-эксплуатация ещё не приняты.
